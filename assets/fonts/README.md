# Noto Sans JP

The application bundles static Noto Sans JP fonts under the SIL Open Font License 1.1 in `OFL.txt`.
The fonts cover Japanese and Latin text and use weights 400 (Regular), 500 (Medium), 600 (SemiBold), and 700 (Bold).

Source: [Google Fonts Noto Sans JP variable font](https://github.com/google/fonts/blob/main/ofl/notosansjp/NotoSansJP%5Bwght%5D.ttf).
The source SHA-256 is `c2f3b4d463500a2ddcd3849cded1fceeb9fd6d1c32e6cbecd568453ba50fc68f`.

Each static font was generated with fontTools 4.64.0 by loading the source with `TTFont`, calling `instantiateVariableFont(font, {'wght': weight}, inplace=True)`, and saving the result.
Static instances make the selected weight explicit for desktop font rendering.
